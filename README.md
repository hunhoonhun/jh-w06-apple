# 🍎 사과 + APPLE 게임

숫자가 열린 사과 보드에서 인접한 칸을 드래그해 합을 만들고 수확하는 퍼즐 게임입니다.

## 게임 소개

- 8×8 사과 모양 보드에 1부터 9까지의 숫자가 무작위로 나타납니다.
- 마우스나 터치로 상하좌우 또는 대각선으로 인접한 숫자를 이어 선택합니다.
- 선택한 숫자의 합이 양의 10의 배수이면 수확에 성공합니다. 선택한 칸 수만큼 점수를 얻습니다.
- 수확한 칸은 사라지고, 같은 열의 위쪽 숫자가 아래로 내려오며 맨 위에는 새 숫자가 채워집니다.
- 제한 시간은 60초입니다. 최고 점수를 갱신하면 꽃가루와 컨페티 효과가 나타납니다.

## 어떻게 만들었나요

Copilot Agent에 게임 규칙과 화면 구성을 요청해 기본 게임을 만든 뒤, 브라우저에서 직접 실행하며 기능을 단계적으로 다듬었습니다. 사과 모양 보드, 시작·중지·숫자판 새로고침, 열 단위 낙하, 신기록 축하 효과를 추가하고 실제 드래그와 모바일 화면에서 동작을 확인했습니다.

HTML, CSS, Vanilla JavaScript를 별도 파일로 구성했으며 외부 라이브러리 없이 동작합니다.

## 실행 방법

저장소의 `index.html`을 브라우저에서 열면 실행됩니다. 별도의 패키지 설치나 빌드 과정은 필요하지 않습니다.

현재 공개 배포 링크는 없습니다.

## 커스터마이징한 부분

- 예시의 2분·합 10 규칙 대신 60초 제한과 합이 10의 배수인 경우 수확하도록 변경했습니다.
- 숫자는 1~9에서 무작위로 생성하며 대각선을 포함한 8방향 이동을 허용합니다.
- 게임 시작 전에는 보드를 비워두고, 시작 버튼을 눌러야 타이머가 작동합니다.
- 중지 버튼으로 현재 점수에서 게임을 끝낼 수 있습니다.
- 숫자판 새로고침 버튼으로 진행 중 점수와 시간을 유지한 채 숫자판을 다시 섞을 수 있습니다.
- 최고 점수 갱신 시 꽃가루와 컨페티 애니메이션을 재생합니다. 최고 점수는 페이지를 새로고침하면 초기화됩니다.
- 보드의 각 행 폭을 조절해 사과 실루엣을 만들고, 작은 화면에서도 사용할 수 있도록 반응형으로 구성했습니다.
